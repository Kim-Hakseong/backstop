# Fonts

Both families are used under the SIL Open Font License 1.1 and are redistributed
here as latin-subset woff2 files so the console renders identically with no
network access.

- **Inter** — Rasmus Andersson. https://rsms.me/inter/ · SIL OFL 1.1
  `Inter-var.woff2` is the variable font covering weights 100–900.
- **IBM Plex Mono** — IBM. https://github.com/IBM/plex · SIL OFL 1.1
  `IBMPlexMono-400.woff2`, `IBMPlexMono-500.woff2`

Subsets were taken from the Google Fonts CDN (basic latin, U+0000–00FF) and are
committed to this repository. Nothing is fetched at runtime.
